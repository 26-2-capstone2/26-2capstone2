\## 2. PHY 오류율 정책 검증 (10월 31일)



검증 대상: 최신 `26-2capstone2-GSL (2)` 코드



`getPERfromSNR.m`의 동작을 MATLAB 명령 창에서 직접 확인했다.



\- 대역폭과 정보 전송률이 누락된 경우: NaN 및 해당 상태 반환 확인

\- Eb/N0 = -1dB: PER = 100%, `LOW\_SNR\_UNIT\_CWER\_ASSUMPTION`

\- Eb/N0 = 24dB: PER = 0%, `HIGH\_SNR\_ZERO\_CWER\_ASSUMPTION`



논문 오류율 곡선 범위 밖의 0% 및 100% 처리는 실제 측정 결과가 아닌 시뮬레이션 근사 정책이다.



\## 3. 발견된 검증 코드 불일치



최신 코드에서 `verify\_packets` 실행 시 5번째 줄의 assert 실패를 확인했다.



`configGSL.m`에는 대역폭과 정보 전송률이 각각 50e6으로 설정되어 있지만, 해당 테스트는 두 값이 누락된 상황을 가정한다.



또한 곡선 범위 밖에서 NaN을 기대하는 기존 테스트가 최신 `ZERO\_CWER` 및 `UNIT\_CWER` 정책과 충돌할 가능성이 있다.



권장 수정 방향:



\- 대역폭·정보율 누락 테스트에는 별도 CFG 사용

\- 곡선 범위 밖 테스트에는 최신 근사 정책 반영

\- 미확정 PHY 결과 검증은 별도 CFG로 유지



검증 코드 수정은 GSL 담당자에게 요청할 예정이다.
