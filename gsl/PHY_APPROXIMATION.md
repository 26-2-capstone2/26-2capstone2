# 전 범위 오류율 근사 (2026-10-31)

강화학습 전송 제어의 상대 비교를 위한 연구 가정입니다. 전 범위에서 검증된 실제 수신기 모델을 의미하지 않습니다.

| 감쇠 후 정보 Eb/N0 | 기본 처리 | 근거 구분 |
|---|---|---|
| 공개 곡선 하한 0dB 미만 | CWER=1 → PER=1 | 연구 가정: 실패 포화 |
| 공개 곡선 범위 약0~2.20026dB | 기존 CWER를 log10 공간에서 보간 → PER=1-(1-CWER)^2 | JPL Figure14를 숫자로 옮긴 표 |
| 공개 곡선 상한 초과 | CWER=0 → PER=0 | 연구 가정: 성공 포화 |

경계점 자체는 논문 표 값을 사용합니다. 슬라이더 환경 감쇠(dB)와 위 기준의 Eb/N0(dB)는 다른 변수입니다. 감쇠를 늘리면 수신 SNR/Eb/N0가 낮아집니다. 신호가 강한 쪽의 실제 오류율이 정확히 0임을 입증한 것은 아닙니다.

configGSL의 highSNRPolicy='ZERO_CWER', lowSNRPolicy='UNIT_CWER'를 사용합니다. 높은 신호 구간을 곡선 마지막 CWER로 두는 민감도 실험은 highSNRPolicy='CONSERVATIVE_ENDPOINT'로 실행할 수 있습니다. 엄격한 미확정 처리는 두 정책을 'UNRESOLVED'로 설정합니다. 잘못된/누락된 SNR이나 대역폭 정보까지 성공·실패로 바꾸지는 않습니다.

각 패킷 phyStatus에 JPL_FIGURE14_LOOKUP / HIGH_SNR_ZERO_CWER_ASSUMPTION / LOW_SNR_UNIT_CWER_ASSUMPTION을 기록합니다. HO/연결 불가 패킷은 PHY를 시도하지 않아 NOT_EVALUATED입니다. 그림 상단에는 범위 밖 근사 적용 개수와 정책을 표시합니다.

## 화면 연동

슬라이더를 놓거나 [감쇠 적용]을 누르면 같은 600초 기하·패킷 ID별 난수로 다시 계산합니다. 성능 창, 채널/손실 구간 창의 SNR 곡선·On time/Lost/Late 점·연속 손실 stem 그래프, 번호별 패킷 창을 모두 갱신합니다. 재생 시각은 유지하며 지구본은 열지 않습니다. 시각별 날씨 변화가 아닌 전체 세션에 일정한 환경 감쇠를 적용하는 비교입니다.

낮은 감쇠에서 손실이 거의 같고 높은 감쇠에서 모두 손실되는 현상은 포화 모델의 정상 동작입니다. 모든 dB에서 다른 결과를 보장하거나 강제하지 않습니다.

## 연구 비교

무제어·임계값 제어·RL에 동일 모델·트래픽·평가 구간·전력/복제 예산을 적용합니다. 여러 난수 시드와 높은 SNR 끝값 정책으로 결론의 민감도를 확인해야 합니다. 이 파일은 모델 가정이며 RL의 효과를 검증한 결과는 아닙니다.
