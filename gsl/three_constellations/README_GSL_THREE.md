# 세 위성군 GSL 비교 — GS에서 첫 수신 위성까지만

## 실행

GitHub에는 코드와 실행에 필요한 PHY 표만 포함한다. 대용량 실험 기록은 각 PC에서 생성된다. 저장된 결과가 없는 첫 실행은 30개 에피소드 학습과 총 90회 평가를 수행하므로 시간이 걸린다. 이후 실행은 해당 PC의 저장 결과를 연다.

상위 `gsl` 폴더를 MATLAB 현재 폴더로 설정한다.

```matlab
R = main_gsl_three_constellations;
```

저장된 최종 결과를 바로 연다. 비교 그래프, 학습 곡선, 후보 SNR 표, 번호가 붙은 패킷 재생 창이 열린다. 위성군/정책을 바꿔 첫 평가 시드의 상세 결과를 확인한다. 재생·일시정지·배속은 패킷 창에서 조작하며 후보 표가 같은 시간으로 따라간다. 후보 창의 시간 바를 움직여도 패킷 창이 함께 이동한다.

처음부터 다시 학습하고 90회를 재계산하려면:

```matlab
R = main_gsl_three_constellations('run');
```

이전 단일 위성군/고도각 선택 실험은 `main_gsl_toolbox_simulation`으로 그대로 실행할 수 있다.

## 범위와 공통 조건

- 6×11(66개), 20×20(400개), 36×36(1296개) 이동 격자. 기존의 구면 격자 운동·간격(200/400 km)·고도 780 km를 유지한다. 실제 이리듐/스타링크 궤도망이라고 주장하지 않는다.
- 지상국 37°N, 128°E, 고도 0 m. 최소 고도각 25°가 유일한 후보 범위 조건이다. 추가 반경·PER 임계값·top-K 제한은 없다.
- 전체 600초, 매초 선택, 160 B·60 pps = 36,000패킷. GSL 기한 20 ms, 실제 위성 간 전환 때만 중단 100 ms. 최초 연결은 핸드오버로 세지 않는다.
- 환경감쇠 8 dB, 기존 툴박스 QPSK·AR4JA·AWGN 표 유지. 대역폭/정보율 50 MHz/50 Mbps, 패딩 반영 전송시간 40.96 us.
- SNR은 거리 기반 링크 버짓 + 위성별 시간 상관 Gaussian 변동(표준편차 1 dB, 상관시간 5초)으로 계산한다. 실측 날씨나 채널이라고 주장하지 않는다.
- 위성 간격을 고정했으므로 전체 망 크기가 커져도 GS 주변의 가시 후보 수가 늘지 않을 수 있다.
- 빠른 좌표 계산은 기존 `movingGSLGridEphemeris` 결과를 사용한다. Toolbox AER/가시성과 대조했으며, 검증 오차 한계는 0.1 m / 1e-5도다. 부호화·변조 표는 기존 툴박스 측정값이다.

**ISL 내부 전달·큐·목적지 라우팅·TTL·ISL 손실은 이번 코드에서 계산하지 않는다.** 우리 지표의 분모는 GS가 생성한 전체 패킷, 도착지는 선택된 첫 수신 위성이다.

## 비교 방식

1. `MaxSNR`: 매초 모든 가시 후보 중 SNR 최대.
2. `MaxSNR_Hysteresis`: 현재 위성이 여전히 보이면 0.1 dB 이상의 SNR 개선이 있을 때 전환.
3. `DDQN`: 새로 학습한 후보별 점수 모델. 각 후보를 같은 10→64→64→1 신경망으로 평가해 최댓값을 선택한다. 현재 후보 Q값보다 0.02 이상 개선될 때 전환하는 Q-margin을 적용한다. **Q값 0.02는 0.1 dB와 다른 단위의 실험 설정**이다.

기존 13슬롯/79입력 DDQN 체크포인트를 그대로 재사용하지 않는다. 이 모델은 새 상태 구조로 처음부터 학습했다. 후보 수가 바뀌어도 신경망 크기를 바꾸지 않으며 모든 가시 후보를 평가한다. `Double DQN`은 온라인망이 다음 후보를 고르고 타깃망이 그 값을 평가한다. 후보를 SNR 순으로 표시하는 것과 최종 선택 정책은 별개다.

State 10개: SNR, 직전 SNR 변화, 고도각, 현재 연결 여부, 과거 측정 유무, 현재 PHY 표의 예상 성공률, 관측된 직전 연속 손실, 현재 연결 SNR, 현재 연결 대비 SNR 차이, 전체 위성 대비 가시 후보 비율. 위성 ID는 식별용이며 신경망에 임의 숫자로 입력하지 않는다. 미래 난수/SNR/패킷 결과는 보지 않는다.

Reward = 기한 내 도착 비율 − 0.3×연속 손실 벌점 − 0.1×핸드오버. 연속 손실 벌점은 패킷마다 `min(streak/60,10)`의 평균이다. 계수는 초기 연구 설정이며 최적/표준 값이 아니다. GSL 도착은 다음 선택 시점 이전에 관측되는지 검사한다.

학습 30에피소드(세 크기 교대로 각 10회), 1개 학습 초기화 시드. 평가 10개 별도 시드, 3정책 × 3크기 = 90회. 같은 크기·같은 평가 시드는 세 정책에서 같은 SNR 변동과 패킷 난수를 사용한다. 평가 중 학습/epsilon 탐험은 없다. 학습 곡선은 탐험 성능이며 최종 평가 성능과 구분한다. 학습 안정화/최적성/다른 초기화에서의 일반화가 입증됐다는 뜻은 아니다.

## 저장 파일

- `summary.csv`: 9조건의 10회 평균·표본 표준편차.
- `runs.csv`: 90회 개별 손실률·기한 내 도착률·최대 연속 손실·핸드오버·원인별 손실 및 검증식.
- `paired_differences.csv`: 같은 시드에서 DDQN − 각 기준 정책 차이. 95% t 구간은 이 모델과 설정에 조건부인 10개 난수 시드 평균의 근사 구간이며, PHY 표의 추정 오차나 학습 초기화 불확실성을 포함하지 않는다.
- `training.csv`, `agent.mat`: 학습 기록과 신경망 체크포인트.
- `grid_크기/repeat_XX_candidates.csv`: 각 반복 600초의 **모든 가시 후보** SNR·고도각·PER·위성 좌표. 세 정책이 공유하는 채널 기록.
- `grid_크기/정책/repeat_XX_packets.csv`: 매 반복 36,000개 원본 패킷의 전체 상세 기록.
- `..._loss_runs.csv`: 연속 손실 구간과 길이.
- `..._decisions.csv`: 매초 선택된 위성과 핸드오버.
- `..._isl_input.csv`: 첫 위성에 실제 도착한 패킷만 내보내는 ISL 입력.
- `satellite_map_크기.csv`, `geometry_크기.mat`: 공통 위성 ID/좌표와 움직임·가시성 데이터.

ISL 입력의 `packet_id`는 원래 GS 패킷 번호라 중간에 빠진 번호가 있을 수 있다. 다시 1번부터 매기지 않는다. `generation_time_s`는 GS 생성 시각, `isl_entry_time_s`는 **전파·전송·수신처리를 포함한 실제 첫 위성 수신 시각**이다. `p,s`는 화면용 1-based, `p_zero_based,s_zero_based`는 팀원 코드용 0-based다. `satellite_id=(p-1)*satsPerPlane+s`다. 패킷 크기 160 B와 단일 흐름 ID도 포함한다. 모든 시간은 해당 실행 시작 기준 초다. 각 반복의 패킷 ID 범위는 독립이므로 다른 반복 파일을 한 흐름으로 섞지 않는다.

GSL 기한을 넘었더라도 실제 수신한 패킷은 ISL 입력에 포함하고 `gsl_on_time`으로 구분한다. ISL의 최종 목적지/기한/라우팅은 ISL 팀에서 설정한다. 실패 패킷은 입력에 포함하지 않지만 원본 패킷 CSV에 원인과 위치를 남긴다.

## 검증

`verify_gsl_three_core`: Toolbox 좌표 대조, 빠른 패킷 계산과 기존 기준 함수 비교, 0/1/13/41/100 후보, DDQN 경험 재생·기울기 검사.

모든 평가에서 `생성−수신 = PHY+핸드오버+연결불가`를 검사하고 미확정 패킷 0개를 확인한다. 수신 성공률을 높이려고 PHY 표나 송수신 전력은 조정하지 않는다.
