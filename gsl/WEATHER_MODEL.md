# 날씨 3조건 GSL 비교

## 실행

바탕화면 `codex/1029`를 MATLAB Current Folder로 맞춥니다.

기존 **main_gsl_simulation.m을 그대로 실행(F5)** 합니다. 인자·기상 설정·명령어를 바꿀 필요가 없습니다. 기하는 한 번 계산하고 세 날씨를 자동 측정합니다.

기존 **UDP SESSION PERFORMANCE** 창 상단에 세 날씨의 생성·손실·손실률·기한 내 도착률·최대 연속 손실·평균 대기 감쇠를 함께 표시합니다. 오른쪽 **날씨 선택**에서 맑음/흐림/비를 고르면 같은 네 개 그래프, SNR·손실 구간 창, 번호별 패킷 창이 선택 조건으로 바뀝니다. 3D 시간과 위성망은 그대로 유지하며 다시 계산하거나 창을 새로 열지 않습니다.

고급용 별도 일괄 실행 함수 main_gsl_weather_comparison도 남아 있지만 일반 실행에는 필요 없습니다.

고급용으로 시작 조건을 지정하는 명령도 사용할 수 있습니다.

```matlab
R = main_gsl_simulation(configGSL('clear'));
R = main_gsl_simulation(configGSL('cloudy'));
R = main_gsl_simulation(configGSL('rainy'));
```

처음 표시 조건은 맑음이며 상단 요약은 세 조건 모두의 최종값입니다. 과거 results_packets의 671개 손실 결과는 인공 감쇠 시험의 기록이며 새 날씨 결과가 아닙니다.

## 공통 조건

**Ku uplink 14 GHz / 잡음 대역폭 50 MHz / 정보율 50 Mbps / QPSK·AR4JA r=1/2 k=1024.** 부호화 후 비트율은 100 Mbps로 해석합니다. 600초·160 Bytes·60 pps, 지상국→첫 위성까지 평가하고 GSL 기한은 실험 가정 20ms입니다. 위성망, serving 선택, 핸드오버 100ms 중단, 패킷별 PHY 난수는 동일합니다.

## 기상 입력

| 값 | 맑음 clear | 흐림 cloudy | 비 rainy |
|---|---:|---:|---:|
| 지표 기온 [°C] | 20 | 20 | 20 |
| 지표 전체 기압 [Pa] | 101325 | 101325 | 101325 |
| 지표 수증기 밀도 [g/m³] | 7.5 | 12 | 15 |
| 구름 액체 수분 밀도 [g/m³] | 0 | 0.5 | 0.5 |
| 강우율 [mm/h] | 0 | 0 | 10 |

**이 수치는 관측된 특정 날짜의 날씨가 아니라, 명시적으로 선택한 기상 시나리오 입력입니다.** weatherProfile.m에서 관측값이나 팀 합의값으로 변경할 수 있습니다. 맑음/흐림이라는 명칭 자체가 유일한 기상 수치를 결정하지 않습니다. 수증기와 구름의 액체 물은 서로 다른 물리량입니다. 0.5g/m³ 구름 수분은 MathWorks의 적운 예제에도 사용되는 값이며, 나머지 수치·층 높이 등은 연구 가정입니다.

## 계산 방법

1. **기체 P.676-12 Annex 1**: 산소·수증기의 선별 흡수식과 건조 공기 연속 흡수를 계산합니다. 지표부터 20km까지 250m 층으로 나누고, 각 층에서 온도·건조 기압·수증기 밀도를 적용합니다. 지표 기압은 전체 기압이며 수증기 분압을 뺀 값이 흡수식에 들어갑니다.
2. **구름 P.840-8**: 이중 Debye 유전율 식으로 액체 수분의 단위 길이 감쇠를 계산합니다. 구름은 지상 1–2km의 균일 층으로 가정합니다. 비가 없더라도 구름 감쇠를 계산합니다.
3. **비 P.838-3**: 주파수·편파·고도각으로 k, alpha를 계산하고 `gammaR = k * R^alpha` [dB/km]를 적용합니다. 비 층은 지상부터 3km까지 균일하다고 가정합니다. 45° 편파 기울기(원편파 등가)를 사용합니다.
4. 지구 곡률과 실제 고도각으로 각 층 안의 경로 길이를 계산합니다. **강우를 550km 전체 위성 경로에 적용하지 않습니다.** 세 감쇠를 합쳐 SNR에서 한 번만 뺍니다. 기존 0.2dB 천정 손실을 중복해서 더하지 않습니다.
5. SNR→Eb/N0→기존 JPL CWER→PER→패킷 결과→손실률/기한 내 도착률/연속 손실 순서로 계산합니다.

시간에 따른 변화는 위성 거리·고도각·핸드오버에서 발생합니다. 각 600초 동안 기상 입력은 일정하며, 기존 인공 10dB 감쇠와 임의 0.7dB 잡음은 사용하지 않습니다. 따라서 현재 모델은 실제 폭우 시간 시퀀스나 돌풍·차폐·신틸레이션을 재현하는 모델이 아닙니다. 대기 온도는 11km까지 6.5K/km 감소, 위쪽은 등온, 수증기 밀도는 높이 2km마다 지수적으로 감소하는 단순 연직 프로파일입니다. 관측 연직 자료·수평 비균질성·굴절·우적 입자 변화·젖은 안테나·실제 장비값은 추가 검증 대상입니다.

P.618의 **연간 초과확률**을 순간 패킷 손실 확률로 사용하지 않습니다. 이 구현은 기상 입력을 고정한 층별 흡수 모델이며 P.618 전체 통계 가용도 모델 구현을 주장하지 않습니다. 수신기가 위성인 uplink이므로 지상국 sky noise를 위성 G/T에 그대로 더하지 않습니다.

## 결과

`results_weather/clear`, `cloudy`, `rainy` 각각에 기존 형식의 성능·SNR/패킷 상태/연속 손실 그래프, 전체 패킷 CSV/MAT, 요약, ISL 인계 파일을 저장합니다. `weather_attenuation.csv`에는 가스·구름·비의 감쇠를 각각 기록하고 `weather_inputs.json`에는 사용한 기상 입력을 저장합니다.

상위 폴더의 `weather_comparison.csv/.mat/.png`에서 세 조건을 비교합니다. 같은 폴더에서 반복 실행하면 같은 조건 결과를 갱신합니다. MATLAB 추가 통신 툴박스 함수 없이 수식을 직접 계산하며 계수표를 함께 배포합니다.

**주의:** 비가 와도 SNR이 복호에 충분하면 손실이 거의 늘지 않을 수 있습니다. 특히 현재 공개 CWER 곡선은 Eb/N0 약 2.2dB까지이고, 그 위쪽은 동일 끝값을 쓰는 보수적 근사여서 작은 날씨 차이를 패킷 오류율로 구분하지 못합니다. 날씨별 SNR 차이와 오류 곡선 범위를 함께 봐야 하며, 차이를 만들기 위해 송신 전력을 임의로 낮추지 않습니다. 단일 seed의 작은 손실 수는 실측 평균이나 신뢰구간이 아닙니다.

- [ITU-R P.676-12](https://www.itu.int/rec/R-REC-P.676-12-201908-I/en): 기체 스펙트럼 흡수식.
- [ITU-Rpy](https://github.com/inigodelportillo/ITU-Rpy): P.676-12 계수 CSV와 기체 식의 구현 참고. 원본 MIT 라이선스는 weather_data/LICENSE_ITU_Rpy.txt에 포함했습니다. 표는 v12_lines_oxygen.txt, v12_lines_water_vapour.txt에서 가져왔습니다.
- [MathWorks 구름 감쇠 설명](https://www.mathworks.com/help/phased/ref/fogpl.html): 0.5g/m³ 적운 예제와 균일 경로 가정.

`verify_weather`는 ITU rain 계수 기준값, 성분 분리, 경로 길이·고도각, 감쇠 중복 방지, 인공 감쇠 제외, 원본 ID별 같은 난수·핸드오버를 검증합니다. `verify_uplink`는 패킷 지표·기한·손실 구간을 검증합니다. 전체 대기 모델의 실측 보정까지 완료했다는 뜻은 아닙니다.
