Q 목표값 및 후보 비교 구조 점검

계산 점검: 보상 + 할인율 × 다음 온라인 네트워크가 고른 후보의 타깃 Q값을 사용하고 있음. 종료/후보 없음에서는 다음 Q를 더하지 않음. 산술 오류는 확인되지 않음.
실제 선택에는 Q 여유값 0.02가 있지만 학습 목표는 순수 최대 Q를 사용함. 두 방식 차이는 1회 백업에서 최대 0.019. 이 수치를 누적 학습 오차의 상한으로 볼 수는 없음.
입력 구조 점검: 한 후보의 기존 입력이 같으면, 다른 비연결 후보의 신호가 달라져도 그 후보 점수는 그대로임. 구조적인 정보 누락 가능성이지 실제 실패의 유일한 원인이라는 증명은 아님.
이번 변경: 모든 현재 가시 후보 중 가장 높은 예상 수신 성공률 1개를 추가함. 입력 11개에서 12개로 변경.
초기 기존 가중치는 복사하고 추가 입력 가중치만 0으로 설정해 시작 점수를 맞춤.
보상, PHY, 감쇠 6dB, 6x11 위성군, 균일 경험 재생, 학습 시드와 탐색 비율은 유지. 앞선 우선 경험 재생은 사용하지 않음.
기존 100회 모델과 추가 입력 모델을 비교함. 1000회 모델과의 학습량 동일 비교는 아님.

기존 10개 평가 시드
uniform: 손실률 4.0942%, 최대 연속 손실 평균 64.3개, 기한 내 도착률 95.9058%, 핸드오버 131.0회. 10회 전체에서 가장 긴 손실은 145개.
context: 손실률 4.2383%, 최대 연속 손실 평균 56.8개, 기한 내 도착률 95.7617%, 핸드오버 124.4회. 10회 전체에서 가장 긴 손실은 145개.

새 검증 시드 10개: 20275001~20275010
uniform: 손실률 4.2914%, 최대 연속 손실 평균 65.8개, 기한 내 도착률 95.7086%, 핸드오버 139.1회. 10회 전체에서 가장 긴 손실은 187개.
context: 손실률 4.4356%, 최대 연속 손실 평균 51.1개, 기한 내 도착률 95.5644%, 핸드오버 130.0회. 10회 전체에서 가장 긴 손실은 195개.

한계: 학습 초기화는 1개이며, 여러 학습 시드에서의 안정성은 확인하지 않음.
Q값과 기록된 누적 보상의 차이는 표본 기반 진단이며 정확한 기대 Q 오차는 아님.
남은 시간 정보는 아직 입력에 없고, 최고 성공률 1개만으로 후보 전체 상태를 완전히 표현하지는 못함.
원래 모델/보상/환경 파일의 해시는 변경 전과 동일함.
main_gsl_q_context 실행 시 재학습 없이 저장된 비교와 패킷 결과가 열림.

학습 상황 분포: 가장 좋은 후보도 성공률 10% 미만인 시점은 95/60000 (0.1583%).
모든 후보의 모델 PER가 1인 시점은 5/60000.
이는 환경의 모든 가시 후보를 센 통계로, 정책이 선택한 나쁜 위성의 비율과는 다름.
후보 전체가 나쁜 상황의 표본이 적다는 사실은 확인했으나, 이것이 실패의 유일한 원인이라는 인과 증명은 아님.

현재 판단: 기존 모델 교체는 보류. 두 평가 묶음에서 최대 연속 손실 평균은 감소했으나 전체 손실률은 증가했고, 평균 연속 손실 차이의 95% 짝비교 구간은 0을 포함함.
새 10회 평가의 최악 연속 손실은 187개에서 195개로 증가함. 평균 개선을 최악 상황 개선과 혼동하지 말 것.
모델 PER가 1인 후보를 고르면서 더 낮은 PER 대안이 있던 결정은 새 검증에서 기존 8회, 추가 입력 2회. 점수 순위 문제가 완전히 사라진 것은 아님.
Q값과 실제 기록 보상의 차이는 방문 상태가 서로 다른 표본 기반 통계라 정확한 기대 Q 오차 개선의 증명은 아님.
향후에는 후보 전체가 나쁜 구간의 표본 부족과 남은 시간 정보 누락을 보상 변경과 구분해 검토할 필요가 있음. 이번에는 둘 다 추가 변경하지 않음.
입력이 11개에서 12개로 바뀌었으므로 수정 모델은 GSLContextEpisode/GSLContextDoubleDQN으로 사용. 기존 11입력 모델에 그대로 대입하지 말 것.
