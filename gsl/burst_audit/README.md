# 긴 연속 손실의 선택 원인 진단

상위 gsl 폴더에서 `main_gsl_burst_audit`를 실행하면 저장된 3회차·10회차 사례 그래프와 전환 마진 제거 결과를 연다. `'run'` 인수는 동결된 모델의 10회 정확 재생과 마진 제거 10회 평가를 다시 수행한다. 재학습은 하지 않는다.

기존 ddqn_6x11과 maxsnr_comparison의 완료된 로컬 결과가 필요하다. 설정·PHY·신호·패킷 난수는 기존 평가와 같고, 원래 6,000개 선택과 36만 패킷 결과를 정확히 재현한 뒤 Q값을 기록했다. 마진 제거 진단에서만 외부 Q값 마진을 0.02→0으로 바꾼다. 원본 모델과 결과 파일은 보존한다.

`RESULTS.md`의 핵심 결론: 최장 손실 구간에서 마진 차단 0건, 마진 제거 시에도 10회 모두 최장 길이 동일. 신호가 더 나쁜 후보를 Q값이 높게 평가한 사례와, 후보 전체의 품질이 나빠 선택만으로 피하기 어려운 사례가 함께 있다. 보상 가중치가 원인이라고 단정하지 않는다.

`summarize_audit.py <결과폴더>`는 Q 결정 기록과 마진 제거 36만 패킷을 검증하고 보고서를 생성한다. 주 실행 함수가 자동으로 학습 정책을 변경하거나 새 보상으로 재학습하지는 않는다.
