# 최대 연속 손실의 회피 가능성 진단

재학습 없이 1/3/5-step의 기존 평가 10회씩, 총 30회에서 첫 번째 최장 손실 구간을 조사했다.
손실 시작 3초 전부터 마지막 손실이 발생한 초 이후 2초까지의 각 결정에서 모든 가시 위성을 한 번씩 강제 선택했다.
이후에는 원래 학습된 정책과 Q마진 0.02를 그대로 적용해 600초 전체를 재생했다.
총 5,338개 분기이며, 원래 선택을 강제한 분기는 저장된 원래 패킷 결과와 일치하는지 확인했다.

## 핵심 결과

| 모델 | 원래 최대 손실 평균 | 사후 단일 행동 변경 | 낙관적 하한 평균 | 이미 하한과 같았던 회차 |
|---|---:|---:|---:|---:|
| 1-step | 39.7 | 36.4 | 35.3 | 6/10 |
| 3-step | 47.9 | 36.4 | 35.3 | 3/10 |
| 5-step | 42.8 | 36.4 | 35.3 | 4/10 |

사후 변경으로 전체 최대 손실이 감소한 회차는 각각 4/10, 6/10, 5/10이다.
대체 행동은 진단 창의 최대 손실, 총 손실, 전환 수를 순서대로 최소화하는 것으로 골랐다.
미래 결과를 보고 고른 행동이므로 36.4개는 새 온라인 정책의 성능으로 제시하면 안 된다.

낙관적 하한은 매 패킷의 공통 난수를 모든 가시 후보의 PER와 비교해 모든 후보가 실패할 패킷만 손실로 둔 것이다.
전환 중단도 제거한 낙관적인 기준이다. 원래 손실과 모든 최종 대체 경로에 이 실패 패킷이 포함되는지 확인했다.
하한이 120개이고 실제도 120개인 회차는 현재 고정 채널·PHY 표·공통 난수·재전송 없음 모델에서 선택만으로 120개보다 줄일 수 없다.
현실 위성 링크의 오류가 정확히 100%라는 뜻이나 후보별 독립 오류를 사용하는 다른 모델에도 같은 결과라는 뜻은 아니다.

1-step 구체 사례:
- 시드 20279306: 실제 120개, 낙관적 하한도 120개. 해당 구간의 120개 모두 모든 후보가 공통 난수에서 실패했다.
- 시드 20279305: 최초 선택을 위성 44에서 33으로 바꾸면 62개→43개, 전체 손실 1,612→1,611개, 핸드오버 155→156회.
  최초 초의 PER는 44번 약 0.9983, 33번 약 0.9772로 둘 다 나쁘다. 적은 수신 성공 차이도 최대 연속 손실을 크게 바꿀 수 있다.
- 시드 20279303: 522초의 선택 변경으로 41개→35개.
- 시드 20279308: 5초의 선택 변경으로 68개→63개.

Q마진에 의한 raw argmax 전환 차단은 검사 창에서 1-step 1회, 3-step 1회, 5-step 0회였다.
두 차단은 모두 245초로, 해당 모델의 실제 최장 손실이 끝난 이후였다. 검사한 최장 손실의 시작 전·진행 중에는 차단 사례가 없었다.
이 결과만으로 모든 구간에서 Q마진이 무해하다거나 Q함수 자체가 정확하다고 결론 내리지는 않는다.

## 원인에 대한 해석

보상 불일치가 있는 것은 앞선 점검에서 확인했지만, 이번 최장 손실을 모두 보상 탓으로 설명할 수는 없다.
1-step은 이미 6회에서 현재 모델의 낙관적 하한과 같고, 평균 39.7개와 하한 평균 35.3개의 차이는 4.4개다.
이번 10개 시드에서는 위성 선택만 바꿔 최대 연속 손실을 대폭 줄일 여지가 제한적이다.
반면 4회는 실제로 다른 선택으로 줄일 수 있었으므로 정책 개선 여지도 존재한다.
그 대체 행동이 새로운 환경에서도 기대 성능이 좋은지, 보상이 선호하는지, 학습 가능한지는 별도 검증 사항이다.

## 실행 및 자료

- 상위 `gsl`에서 `main_gsl_burst_counterfactual`: 저장 그림 열기, 재학습·재시뮬레이션 없음.
- `run_entry.m`: 진단 전체 재실행.
- `results/cases.csv`: 30회 원본·대체·하한 요약.
- `results/probe_states.csv`: 190개 결정의 현재 선택, Q차이, PER, Q마진 여부.
- `results/all_branches.csv`: 5,338개 후보 행동 분기.
- `results/n*_repeat_*_packet_comparison.csv`: 원본·대체·하한의 전체 36,000개 패킷 비교.
- `verification.json`: 1,080,000개 패킷 비교 독립 검증.

모델 가중치 및 원래 실험 파일은 수정하지 않았다. 분석은 모의 환경 내 조건부 사후 분석이며 실제 무선 링크의 인과 실험으로 일반화하지 않는다.
