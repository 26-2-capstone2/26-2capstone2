# GSL 연구 코드 및 결과 — 2026-11-26

범위는 지상국 → 선택한 첫 위성이다. 팀원의 Mock ISL 통합 브랜치는 수정하지 않았다.
6×11 이동 격자, 환경 감쇠 6 dB, Toolbox PHY, 600초, 60 packets/s, 160 B 조건이다.

## 동일 조건 10회 평가 결과

| 지표 | 최대 SNR (학습 없음) | DDQN 100회 학습 | DDQN 1,000회 학습 |
|---|---:|---:|---:|
| 손실률 (%) | 6.0467 | 4.0942 | 4.1556 |
| 실행별 최대 연속 손실의 평균 (개) | 56.0 | 64.3 | 81.5 |
| 기한 내 도착률 (%) | 93.9533 | 95.9058 | 95.8444 |
| 핸드오버 (회) | 269.0 | 131.0 | 130.6 |

같은 평가 시드·이동·모든 후보 SNR·패킷 난수·PHY 표를 사용했다.
최대 SNR은 매초 최고 SNR 선택, 별도 히스테리시스 없음. DDQN은 Q점수 차이 0.02의 연결 유지 조건을 사용한다. Q점수 0.02는 dB가 아니다.
DDQN은 손실률과 핸드오버가 감소했으나 최대 연속 손실은 개선하지 못했다. 1,000회 학습이 100회보다 낫다는 결과도 얻지 못했다.

## 보상 점검과 추가 실험

- 기존 보상: 기한 내 수신 비율 − 0.3 × 평균 연속 손실 비용 − 0.1 × 핸드오버 여부. 연속 손실 비용은 패킷별 `min(streak/60,10)`의 평균이다.
- 기존 비용은 매 패킷의 연속 손실 길이를 더하는 구조여서, 최대 연속 손실이라는 평가 지표와 선호가 어긋날 수 있음을 확인했다.
- 우선순위 리플레이, 후보 전체의 품질 입력 추가, 모두 나쁜 구간의 유지/전환 경험 추가를 각각 시험했지만 전체 지표의 안정적인 동시 개선은 확인하지 못했다. 모두 연구용 실험이며 기존 최종 모델을 대체하지 않는다.
- 새 보상: `-lossFraction - 0.3*(runningMax_after-runningMax_before)/60`.
- 600초 총합은 정확히 `-(전체 손실 수 + 0.3*최대 연속 손실)/60`이다. 입력에 현재 최대 손실 기록·남은 시간을 추가했다.
- 누적 비용 대조군과 새 보상 모두 14개 입력, 할인율 1, 별도 핸드오버 벌점 0, 100회 학습으로 비교했다. 실제 100 ms 핸드오버 중단은 그대로 적용한다. 따라서 과거 11/12입력 모델과의 차이를 보상식 하나의 효과라고 해석하지 않는다.

### 새 평가 조건 10개에서의 평균

| 지표 | 누적 비용 대조군 | 새 최대 기록 증가 비용 |
|---|---:|---:|
| 손실률 (%) | 4.5967 | 4.1931 |
| 최대 연속 손실 (개) | 36.8 | 46.6 |
| 기한 내 도착률 (%) | 95.4033 | 95.8069 |
| 핸드오버 (회) | 180.6 | 145.6 |

새 보상도 연속 손실 개선에는 성공하지 못했다. 가중합 목표는 전체 손실 감소를 위해 최대 연속 손실 증가를 허용할 수 있다. 계수 0.3은 연속 손실 기록 10개 증가를 전체 손실 3개 증가와 같은 비용으로 취급한다.
각 방식의 학습 초기값은 하나뿐이므로 여러 초기값의 학습 안정성 검증은 남아 있다. 원래 평가 10개와 새 평가 10개 결과는 구분해서 저장했다.

바탕화면 전체 보관본에는 모델 MAT·그림 FIG/PNG·모든 회차 패킷 로그가 들어 있다.
GitHub에는 MATLAB/Python 코드와 작은 요약 CSV·검증 기록을 올렸다. 대용량 MAT·FIG·전체 패킷 로그는 포함하지 않는다. 따라서 GitHub만 내려받은 경우 저장 결과 뷰어는 필요한 MAT가 없으면 열리지 않을 수 있다. 재생성은 각 폴더의 실행·학습 함수와 README를 확인한다. 무심코 학습 실행 명령을 누르지 않는다.

실행 경로는 개인 PC의 1123 폴더 대신 코드 위치에서 계산하도록 정리했다. 역사적 로그·manifest 안의 원래 경로는 실험 출처 기록이다.
검증: 새 보상 40회 평가의 1,440,000개 패킷 기록 별도 재계산, 보상 총합 등식 20회 검증, 같은 평가 조건의 난수 일치 및 기존 모델 보존 확인.

다음 과제는 최대 SNR에 연결 유지 조건을 적용한 비교군을 추가하고, 긴 연속 손실을 억제하는 목표·경험·Q점수 추정을 함께 검증하는 것이다. 이번 수정으로 실제 PHY 표나 신호 조건을 조절하지 않았다.
