# 최대 SNR / 고도각 / DDQN — 같은 조건 10회

`main_gsl_compare_maxsnr`로 저장 결과 그래프를 연다. `main_gsl_compare_maxsnr('run')`은 최대 SNR 방식 10회만 다시 평가한다. 기존 DDQN과 고도각 방식의 완료된 로컬 평가 자료가 필요하다.

최대 SNR 방식은 학습 없이 매초 고도각 25도 이상인 모든 가시 후보 중 현재 SNR이 가장 높은 위성을 고른다. 히스테리시스·Q값 마진·PER 임계값을 적용하지 않는다. 실제 위성이 바뀌면 동일하게 100 ms 중단한다.

6×11, 6 dB, 600초, 60 pps·160 B, 기한 20 ms. 시드 20269301~20269310과 기존 저장된 동일 움직임·후보 SNR·패킷 난수·PHY 표를 사용한다. 학습/보상/전력/PHY 값은 바꾸지 않는다.

기존 방식과 DDQN을 재학습·재평가하지 않는다. `maxsnr_runs.csv`는 새 평가 10회, `all_runs.csv`는 세 정책 총 30회, `three_policy_summary.csv`는 평균·편차, `ddqn_vs_maxsnr.csv`는 같은 시드에서의 평균 차이와 근사 95% t 구간이다. 구간은 단일 학습 모델과 지정한 채널·PHY 가정에 조건부인 테스트 시드 변동만 반영한다.

각 repeat 폴더에 최대 SNR 방식 36,000개 전체 패킷·연속 손실·선택 기록·재생 자료를 저장한다. 다른 정책 원본은 기존 폴더에서 보존한다.

순수 최대 SNR과 DDQN은 전환 규칙도 다르다(DDQN Q값 마진 0.02). 차이가 나더라도 학습만의 효과로 완전히 분리한 실험은 아니다. 모든 지표를 함께 해석하며 모델 우수성을 결과에 맞춰 단정하지 않는다.
