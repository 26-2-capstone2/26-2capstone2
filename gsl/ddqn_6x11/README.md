# DDQN 6×11 · 6 dB — 100회 학습 + 10회 평가

상위 gsl 폴더에서 `main_gsl_ddqn_6x11`을 실행하면 저장된 결과를 연다. `main_gsl_ddqn_6x11('run')`은 처음부터 다시 학습·평가한다.

- 범위: GS→선택된 첫 위성까지만. ISL 내부 전달은 제외.
- 6×11, 고도 780 km, 간격 200/400 km, 이동 속도 7.5 km/s, 최소 고도각 25도. 모든 가시 후보 사용.
- 600초, 60 pps, 160 B, 도착 기한 20 ms, 실제 전환 100 ms 중단.
- 툴박스 QPSK+AR4JA+AWGN 측정 표, 환경감쇠 6 dB. PHY나 송수신 조건은 변경하지 않음.
- 기존 10개 입력에 최근 최대 5초 SNR 평균 변화량을 추가한 11→64→64→1 후보별 점수망. 새로운 후보는 과거 정보 없음 표시, 가시성이 연속된 과거 샘플만 사용. 미래 정보 사용 금지 검증 포함.
- 과거 연속 손실 상태는 시뮬레이터가 다음 선택 전에 알려준다고 가정한다. 실제 UDP에 손실 통지/ACK 프로토콜을 추가 구현한 것은 아니다. 후보별 성공 확률 입력은 현재 SNR과 기존 PHY 표에서 계산한다.
- 보상은 기존과 동일: 기한 내 수신 비율 − 0.3×평균 min(연속 손실/60,10) − 0.1×핸드오버 여부.
- 온라인망이 다음 행동을 고르고 타깃망이 평가하는 Double DQN. replay 20,000, batch 64, 학습률 0.0003, 할인율 0.95, 8초마다 학습, 100업데이트마다 타깃 갱신, Huber loss, gradient clip 5.
- 전환 마진 Q값 0.02 유지. dB 단위의 히스테리시스와 다름.
- 학습 100회(각 600초). 탐색 확률 1→0.05를 첫 80회 동안 선형 감소, 이후 0.05 유지.
- 학습 시드 20269101~20269200, 평가 시드 20269301~20269310, 신경망 시드 20261123. 평가 때 탐색 0, 가중치 동결.

`runs.csv`: 평가 10회 성적. `summary.csv`: 평균·표준편차·최솟값·최댓값·평균의 근사 95% t 구간. 이 구간은 한 번 학습한 모델과 고정된 시뮬레이션 가정에 대한 테스트 시드 변동이며 학습 초기화·PHY 표 추정 오차는 포함하지 않는다.

각 `repeat_XX`에 36,000개 전체 `packets.csv`, `loss_runs.csv`, `decisions.csv`, `candidates.csv`, 성공한 패킷의 `isl_input.csv`, 재생용 `preview.mat`를 저장한다. 모든 회차의 원본 Packet ID와 실제 첫 수신 시각을 유지한다.

이번에는 기존 방식과 최대 SNR 비교를 실행하지 않는다. 이전 42.8472%는 다른 선택 방식·시드의 단일 결과이므로 여기와 직접 비교해 개선율을 계산하지 않는다. 학습 횟수를 채운 것만으로 수렴이나 우수성을 주장하지 않는다.
