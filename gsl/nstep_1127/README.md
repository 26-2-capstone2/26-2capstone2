# GSL 최대 SNR 히스테리시스 / n-step DDQN 비교

## 목적

학습 없는 최대 SNR 선택에 0/0.1/0.3/0.5 dB 연결 유지 조건을 적용하고,
기존 보상과 물리 환경을 바꾸지 않은 1/3/5-step DDQN과 비교한다.
범위는 GS→첫 위성까지다. 입력 11개, 네트워크 64-64, γ=0.95,
원래 보상 가중치 1/0.3/0.1, DDQN Q마진 0.02를 유지한다.

`experiment_plan.json`이 실험 조건이다. 각 DDQN은 100회 학습하며,
모든 정책은 같은 새로운 시드 20279301~20279310에서 평가한다.
초기 네트워크와 학습 환경 시드는 세 DDQN 모두 같다. 초기값별 반복은 이번 범위에 포함하지 않는다.

## n-step 구현

첫 행동의 Q값을, 연속된 최대 n개의 실제 보상과 γ^h로 할인한 마지막 상태의 Double-DQN 값으로 학습한다.
중간 행동이 선택 당시 online-Q의 최댓값 행동이 아니면 그 행동 이전에서 경험을 끊는다.
탐험뿐 아니라 Q마진으로 인해 비최대 행동을 유지한 경우도 포함한다.
첫 행동은 탐험으로 선택돼도 학습할 수 있다. 두 번째 이후 행동에만 끊기 조건을 적용한다.

이는 off-policy의 중간 행동을 무조건 greedy처럼 처리하지 않기 위한 실용적 trace-cut 보정이다.
저장된 greedy 여부를 쓰므로 오래된 replay와 비선형 근사에 대해 완전한 비편향성을 주장하지 않는다.
n=3/5는 최대 길이이지 모든 경험이 항상 3/5초라는 뜻은 아니다.
실제 길이 분포는 `nstep_target_stats.csv`에 저장한다.
종료 시 짧게 남은 경험을 처리하고 종료 이후의 다른 에피소드는 붙이지 않는다.
실제 경험이 쌓인 뒤 학습하며 행동 선택에 미래 SNR이나 미래 패킷 난수를 주지 않는다.

## 실행

- `hysteresis_entry.m`: 최대 SNR 네 조건 평가.
- `verify_entry.m`: 할인, 종료, trace-cut 및 원본 1-step 행동·가중치 재현 검증.
- `train_n1.m`, `train_n3.m`, `train_n5.m`: 각 100회 새 학습 및 10회 평가. 계산 시간이 필요하다.
- `open_saved_gsl_nstep`: 저장된 비교 그림 열기. 학습하지 않는다.
- `open_saved_gsl_nstep_model(1/3/5)`: 선택한 모델의 10회 패킷 뷰어.

자료만 내려받은 경우 모델 MAT/전체 로그가 없으면 저장 결과를 열 수 없다.
전체 보관본에는 모델, 모든 평가 회차 packets.csv, 후보 표, ISL 입력 변환, preview.mat가 들어 있다.

## 비교 해석

평균 최대 연속 손실은 각 실행의 최대값을 10회 평균한 것이다.
기존에 발표한 20269301~20269310 시드의 수치와 이번 새 시드 결과는 구분한다.
이번 평가는 탐색적 held-out 비교이며, 이후 이 시드로 파라미터를 고르면 최종 테스트로 재사용하지 않는다.
평가 난수 10개는 독립 학습 초기값 10개가 아니다.
기존 보상의 목적과 최대 연속 손실 지표 간 차이는 n-step만으로 없어지지 않는다.

Windows 라이선스 오류가 나면 해당 배치는 결과가 생성됐는지 확인하고 재실행한다.
여러 MATLAB 프로세스의 동시 실행 실패를 성능 결과로 취급하지 않는다.
