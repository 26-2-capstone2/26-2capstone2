# 툴박스 PHY 첫 계산 결과

기존처럼 SNR이 표 범위 밖이라고 오류율을 강제 지정하는 대신, QPSK·AR4JA·AWGN 송수신을 직접 시험해 표를 만들었다. 총 42개 Eb/N0 지점에서 각 1000패킷, 총 42,000패킷을 시험했다. 복호기는 belief propagation 최대 50회다.

| 정보 Eb/N0 | 오류 패킷 / 1000 | 측정 PER |
|---|---:|---:|
| 0 dB | 1000 | 100% |
| 0.5 dB | 997 | 99.7% |
| 0.75 dB | 915 | 91.5% |
| 1 dB | 536 | 53.6% |
| 1.25 dB | 157 | 15.7% |
| 1.5 dB | 15 | 1.5% |
| 2 dB | 0 | 0% 관측 |

0/1000은 참 오류율 0%의 증명이 아니다. 점별 95% Wilson 상한은 약 0.383%다. 1000/1000의 하한은 약 99.617%다. 이 표는 지정한 이상적 AWGN 수신기 조건의 측정값이며 현장 측정값이 아니다.

## 기존 DDQN 로그를 고정한 비교

이전에 공유한 8 dB·히스테리시스 0.1 dB·첫 반복의 위성 선택, SNR, 패킷 난수, 핸드오버 시점을 고정하고 PHY만 재평가했다.

| 지표 | 기존 JPL + 경계 가정 | 툴박스 측정 표 |
|---|---:|---:|
| 생성 패킷 | 36,000 | 36,000 |
| 수신 패킷 | 3,744 | 3,543 |
| 손실 패킷 | 32,256 | 32,457 |
| 손실률 | 89.6000% | 90.1583% |
| 기한 내 도착률 | 10.4000% | 9.8417% |
| 최대 연속 손실 | 1,638 | 1,431 |
| PHY 손실 | 31,320 | 31,521 |
| 핸드오버 손실 | 936 | 936 |

손실률은 약 0.5583%p 증가했고 최대 연속 손실은 줄었다. 한 시드의 고정 경로 재평가이므로 통계적으로 유의한 개선이나 새 PHY에서 DDQN이 학습된 결과로 해석하지 않는다. 새 PHY가 낮은 SNR의 높은 손실을 없애지는 않았다. 하한 가정만이 기존 높은 손실의 유일한 원인이라는 설명은 충분하지 않다.

## 기존 main의 위성 선택 방식으로 계산한 비교

아래는 고도각 기반 선택 + 4도 전환 마진을 쓰는 기존 main의 동일 경로·동일 난수 한 시드 비교다. 위 DDQN 로그와 선택 방식이 달라 수치를 직접 혼합하지 않는다.

| 감쇠 | PHY | 손실률 | 기한 내 도착률 | 최대 연속 손실 |
|---|---|---:|---:|---:|
| 6 dB | 기존 | 41.6889% | 58.3111% | 840 |
| 6 dB | 툴박스 | 42.8472% | 57.1528% | 840 |
| 8 dB | 기존 | 94.2361% | 5.7639% | 4,317 |

모든 600초 실행에서 미확정 패킷은 0개였고, `(생성-수신)/생성`과 `(PHY+핸드오버+연결불가)/생성`이 일치했다.

## 이번에 해결한 것과 남은 것

- 해결: 표 바깥을 임의 0/1로 지정하는 대신, 명시한 송수신 모델로 넓은 범위의 PER를 측정했다. 원본 패킷 복원, 패딩, 펑처링, SNR 단위, 오차 범위를 코드에 반영했다.
- 남음: RF 링크 버짓의 현장 타당성, 실제 기상·간섭·잔여 동기 오류, 낮은 오류율의 정밀 측정, 여러 시드에서의 비교, 새 PHY를 이용한 DDQN 재평가/필요 시 재학습.
- 기존 JPL 그림과 새 표는 복호기와 패킷 처리 조건이 완전히 같은 것이 아니므로, 차이 전부를 예전 경계 처리의 오류라고 해석하지 않는다.

실행 파일과 설정은 `README_TOOLBOX_PHY.md`, 전체 시험 설정은 `phy_toolbox/metadata.json`, 측정 원자료는 `phy_toolbox/ar4ja_qpsk_awgn_160B.csv`에 있다.
