# GSL uplink 검증 (2026-10-29)

MATLAB R2026a에서 실행했습니다. 이 수치는 실측 일반 환경이 아닌, 문서화한 RF·채널 가정의 시험 결과입니다.

## 패킷/채널 검증

`verify_uplink` 통과:

- 60 pps에서 실제 핸드오버의 반개구간 [t,t+0.1)에 정확히 6개 손실
- 원본 ID 순서의 연속 손실 길이·시작·끝 ID
- 기한 초과 도착과 최종 미도착을 분리
- 생성 종료 이후 도착하는 마지막 패킷도 관찰
- 손실 없음/전체 손실의 경계 사례
- 공개 곡선 범위 안 로그 보간, 위/아래 범위 명시적 가정
- 채널 재현성 및 정책 변경 시 원본 ID별 동일 PHY 난수

GSL 도착 기한은 실험 가정 20ms입니다. 대기열 혼잡·ML·전력 제어·복제 전송은 아직 포함하지 않습니다.
