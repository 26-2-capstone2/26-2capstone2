# 환경 감쇠 슬라이더 사용법

기존 main_gsl_simulation.m 실행(F5) → 성능 창 상단의 환경 감쇠량을 0~20dB로 이동합니다. 마우스를 놓으면 0.1dB 단위로 전체 결과를 재계산합니다. 기본 2dB입니다. 별도 추가 감쇠나 기존 날씨 선택은 사용하지 않습니다.

**총 환경 손실 = 슬라이더 값**이며, 기체·구름·강우 손실을 별도로 더하지 않습니다. 자유공간 손실·고정 구현 손실은 유지됩니다. 맑음2/흐림4/비12dB는 사용자 제안에 따른 설명용 실험 예시이며 물리적으로 검증된 날씨별 고정값이 아닙니다. 지구본과 3D 재생은 제거했고 패킷 창의 독립 재생·배속·시각 이동은 유지합니다.

값은 600초 전체에 일정하게 적용됩니다. 동일 원본 패킷 ID별 난수·위성 기하·핸드오버 일정으로 비교합니다. 전송률은 50Mbps로 고정하며 감쇠 때문에 임의로 전송률이 낮아지지 않습니다.

## 전 범위 계산과 근사

공개 CWER 곡선 범위 안에서는 보간하고, 낮은 Eb/N0는 PER=1, 높은 Eb/N0는 PER=0으로 근사합니다. 이제 정상 입력의 슬라이더 0~20dB 전 범위에서 전체 PLR과 기한 내 도착률을 계산합니다. 양 끝은 검증된 데이터가 아닌 연구 가정입니다. 각 패킷 phyStatus와 그림 상단에 근사 적용 여부를 기록합니다. [상세 근거·한계·대체 정책](PHY_APPROXIMATION.md).

SNR/패킷 상태/연속 손실 그래프도 슬라이더를 놓으면 함께 갱신됩니다. 기존 N/A 이미지·검증 기록은 과거 미확정 정책의 결과이며 현재 모델과 다릅니다.
## 저장

결과 저장 → results_attenuation/loss_<값>_dB/. 동일값 저장은 해당 결과를 갱신합니다. 과거 extra_* 폴더와 results_weather는 이전 방식의 기록이며 현재 화면과 구분합니다. 실험 설명·입력 CFG·CSV·MAT를 함께 보관합니다.

[현재 화면](docs/environment_slider.png), [검증](validation_saturation.md). 큐·ACM·ML·중복 전송은 이번 변경 범위가 아닙니다.
