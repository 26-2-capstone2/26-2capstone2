# GSL 후보 SNR·연결 가능성 진단

main_gsl_simulation.m을 실행하면 기존 결과 화면과 함께 GSL Candidate SNR and Availability 창이 열린다.

네 개 그래프에서 다음을 확인한다.

1. 지평선 위 위성 수와 최소 고도각 조건을 통과한 후보 수.
2. 후보들의 최고·최저 SNR과 실제 선택된 위성의 SNR.
3. 연결 후보 없음 / 모든 후보의 모델 PER=1 / PER<1 후보 존재 / PHY 미확정 구간.
4. 현재 고도각 선택 방식과 매초 최고 SNR 선택 방식의 원인별 손실.

상단에는 후보 SNR 범위, 두 선택 방식의 전체 손실률·기한 내 도착률·최대 연속 손실, 현재 모델에서 피할 수 없는 손실 개수와 최대 연속 길이를 표시한다.

## 해석

후보가 없으면 위성 선택으로 연결할 대상이 없다. 후보가 모두 PER=1이면 현재 PHY 가정에서는 어느 후보로 바꾸어도 패킷이 손실된다. 이 두 구간의 패킷 개수와 연속 길이를 하한으로 계산한다. 이는 현재 고도각·링크 버짓·PHY 근사 정책에서의 값이다.

PER<1 후보가 있으면 수신 가능성이 있는 위성을 선택할 수 있다. 실제 손실은 패킷 난수, 핸드오버와 전파 지연 등도 반영한다. 최고 SNR 선택 방식은 매초 가장 높은 후보를 고르며, 위성이 바뀌면 같은 100 ms 핸드오버 중단을 적용한다. 같은 원본 패킷 ID와 같은 PHY 난수를 사용해 비교한다.

진단 창의 최고 SNR 비교는 강화학습 실행 결과나 최적 경로의 보장값으로 정의한 비교가 아니다.

## 슬라이더와 저장

기존 결과 창에서 환경감쇠 슬라이더를 바꾸면 진단 창도 같은 감쇠 값으로 갱신된다. 궤도·가시성·위성별 랜덤 변동·패킷 난수는 동일하게 유지한다.

기본 결과 저장과 결과 저장 버튼에 다음 파일이 추가된다.

- candidate_snr_by_second.csv. 매초 후보 수, 최고·최저·선택 SNR, 최고 후보 위성 ID, PER 및 구간 분류.
- candidate_snr_details.csv. 실제 후보별 위성 ID, 고도각, 거리, SNR, PHY PER 및 선택 여부.
- candidate_regime_summary.csv. 구간 종류별 지속 시간.
- candidate_policy_comparison.csv. 두 선택 방식의 수신·손실·기한 내 도착·연속 손실·원인별 손실.
- candidate_diagnostics.png. 진단 화면.

MATLAB 반환값 R.candidateDiagnostics에서도 진단 Table을 읽을 수 있다. R은 실행 시점의 결과이며 슬라이더를 바꾼 최신 값은 해당 성능 창의 GSLCandidateDiagnostics appdata와 저장 결과에 반영된다.

verify_gsl_diagnostics로 600초 전체 후보의 SNR과 실제 선택 SNR 일치, 후보별 최소·최대 및 PER 분류, 슬라이더 연동, CSV·PNG 저장을 검사한다.
