# DDQN 히스테리시스 10회 비교

실제 40회 실행 완료: [2026-11-15 결과와 해석](RESULTS_GSL_HYSTERESIS_20261115.md).

MATLAB 현재 폴더를 이 gsl 폴더로 지정하고 실행한다.

```matlab
verify_gsl_hysteresis
R = run_gsl_hysteresis_comparison;
```

기본 모델은 `results_ddqn/20261112_163509_823/agent.mat`다. 재학습하지 않고 epsilon=0으로 평가한다. 모델 파일이 없으면 임의 모델로 대체하지 않고 오류를 표시한다. 다른 모델은 첫 인수로 파일 경로를 지정한다.

## 비교 조건

- 환경: 현재 configGSL의 6×11 이동 격자, 환경감쇠 8 dB, 기본 600초·160 Byte·60 pps·기한 20 ms.
- 0 / 0.1 / 0.3 / 0.5 dB 각각 10회, 총 40회.
- 패킷 시드 20265001~20265010. SNR 시드는 config의 snrRandomSeed + 패킷 시드를 2^32로 나눈 나머지.
- 같은 회차의 네 조건은 동일한 위성별 SNR 난수와 패킷별 오류 판정 난수를 사용한다. 조건별 연결 선택은 달라질 수 있다.
- DDQN이 제안한 위성 ID를 먼저 구한 뒤 전환 조건을 적용한다.
- **0 dB는 전환 조건을 끈 기본 DDQN**이다. SNR 개선을 0 dB 이상 요구하는 별도 정책이 아니다.
- 양수 마진에서는 기존 위성이 여전히 보일 때만 `제안 위성 SNR >= 현재 위성 SNR + 마진`이면 전환한다. 부족하면 기존 연결을 유지한다. 현재 위성이 사라졌거나 최초 연결이면 전환을 허용한다.
- 이 규칙은 이번 비교를 위한 명시적인 평가 정책이며, 팀원 실험에 사용한 상세 구현과 동일하다고 가정하지 않는다.

## 결과 파일

실행할 때마다 results_hysteresis 아래에 새 시간 폴더를 만든다.

- summary.csv: 패킷 손실률·최대 연속 손실·기한 내 도착률·핸드오버 횟수의 평균과 표본 표준편차.
- runs.csv: 40회 각각의 결과, 시드, 원인별 손실과 검증식 결과.
- paired_changes_vs_no_gate.csv: 같은 시드의 기본 DDQN 대비 차이. 손실률·기한 내 도착률의 차이 단위는 %p.
- comparison.png / comparison.fig: 네 지표의 평균 ± 표준편차 그래프.
- 각 회차 decisions.csv: 매초 제안 ID·최종 ID·이전 ID·SNR·전환 차단 여부·핸드오버 기록.
- 모든 회차·조건의 packets.csv / loss_runs.csv: 패킷별 기록과 연속 손실 구간. 기본 실행에서는 각각 40개 파일이며 패킷 로그는 합계 1,440,000행.
- log_manifest.csv: 회차·마진·난수 시드별 상세 파일명과 행 수. 중간에 실행이 멈추면 기록된 회차까지만 있으므로 runs.csv와 함께 완료 여부를 확인한다.
- comparison.mat: 설정·모델 경로·시드·요약 결과.

매 실행에서 `(생성-수신)/생성`과 `(PHY+핸드오버+연결불가 손실)/생성`이 일치하고 미확정 패킷이 없는지 검사한다. 연속 손실은 패킷 생성 번호 순서로 계산한다.

2026-11-17부터 전체 반복의 패킷 상세 저장을 기본으로 변경했다. 2026-11-15의 기존 압축 파일은 40회 요약·선택 기록과 첫 반복의 상세 기록만 포함한다. 기존 파일을 복사해서 반복 2~10의 로그로 사용하지 않고 동일 모델·조건·시드로 다시 실행해야 한다. 저장 범위만 바꿨으며 PHY·선택·핸드오버 계산 규칙은 유지한다.

새 이동 격자에서 기존 저장 모델을 평가하는 실험이다. 이전 위성 배치에서의 결과와 직접적인 성능 비교 또는 실제 위성망의 성능 검증으로 해석하지 않는다. 단일 학습 모델·고정 궤적에서 난수만 바꾼 평가라 재학습 시드나 다른 궤적에 대한 일반화까지 확인하는 실험은 아니다.
