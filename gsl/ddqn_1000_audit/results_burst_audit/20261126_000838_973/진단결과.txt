1,000회 DDQN 긴 연속 손실 진단 결과

검증 범위
- 저장된 모델은 변경하지 않음. 추가 학습 없음.
- 10회 평가의 6,000개 위성 선택과 360,000개 패킷 수신/손실을 정확히 재현함.
- 같은 SNR, 가시성, 패킷 난수로 비교함.
- 1,000회 학습의 첫 100회 기록은 기존 100회 실험과 완전히 같음.

확인된 사실
1. 좋은 후보가 있어도 오류확률 100%인 후보를 선택한 순간이 6,000회 결정 중 13회 있었음.
   더 낮은 PER 후보를 선택하지 않았다는 것만으로 모든 선택이 잘못됐다는 뜻은 아님.
   현재 연결 유지와 핸드오버 비용, 미래 보상이 함께 고려되기 때문임.
2. 실제로 Q 순위가 결과와 맞지 않은 사례가 확인됨.
   7번째 평가 4초: 선택 위성10 Q=16.31393, PER=1. 최고 SNR 위성44 Q=15.93124, PER=0.97292.
   같은 상태에서 위성10의 1초 예상 보상은 -0.55250, 위성44는 -0.21076.
   해당 선택 한 번만 바꾸고 이후 frozen DDQN을 사용했을 때 실제 할인 누적 보상은 15.02325 -> 16.46221.
   10번째 평가 20초: 선택54 Q=16.80340, 대안33 Q=16.73028. 할인 누적 보상은 14.40174 -> 14.98734.
   이는 저장된 한 채널 실현값에서의 진단이며, 모든 미래 채널에서 대안이 우월함을 증명하지는 않음.
3. Q 여유값 0.02를 제거하는 비교도 수행함.
   평균 최대 연속 손실: 81.5 -> 77.8개.
   7번째 평가: 188 -> 151개. 나머지 9회 최대값은 동일.
   평균 손실률: 4.15556 -> 4.18278%로 오히려 증가.
   그러므로 전환 여유값만 제거해도 전체 문제가 해결되는 것은 아님.
4. 보상은 지정한 식대로 계산됨.
   onTime*1 - 평균 연속손실비용*0.3 - 핸드오버*0.1.
   선택한 행동의 보상을 별도 계산해 환경 결과와 일치함을 검증함.
   연속손실비용은 각 패킷의 min(현재연속손실/60,10)을 평균한 값.
   에피소드 최대 연속 손실 자체를 직접 최적화하는 식은 아님.
5. 모든 후보가 나쁜 구간도 존재함.
   10번째 평가 21초 최고 SNR 후보도 현재 툴박스 기반 테이블의 PER=1.
   7번째 평가 5초와 10번째 평가 22초에서는 한 번 선택을 바꿔도 해당 저장 채널의 결과가 같았음.
   테이블의 0/1은 유한 표본에서 관측된 값이며 실제 확률이 정확히 0/1임을 뜻하지 않음.

해석과 다음 순서
- 계산 오류나 표시 오류보다는 드문 저신호 상태에서의 Q 순위 부정확성이 확인됨.
- 왜 Q 순위가 부정확해졌는지는 아직 원인을 확정하지 못함.
- 나쁜 신호 구간의 학습 표본, Q 추정 오차, 보상 목표와 평가 지표의 차이를 각각 검토할 필요가 있음.
- 가중치를 여러 개 한꺼번에 바꾸지 말고, 저신호 전환 규칙 또는 보상 변경을 별도 실험으로 비교할 것.
- 이번 진단에서는 기존 정책/보상/학습 모델을 변경하지 않음.
