# GSL uplink 패킷 측정 (2026-10-29)

## 실행

MATLAB Current Folder를 이 폴더로 맞춘 뒤 실행합니다.

```matlab
R = main_gsl_simulation;
```

기존 `main_gsl_simulation.m` 이름을 유지합니다. 3D 창의 기본 재생·일시정지·배속·시간 이동 기능을 사용하면 패킷 창도 같은 시간을 따릅니다. 계산은 먼저 완료하고 재생 시간에 맞춰 결과를 공개합니다. 실제 UDP 소켓 전송이나 실시간 RF 실험이 아닙니다.

## 이번 평가 구간

**지상국에서 생성 → 첫 번째 수신 위성 도착**까지의 uplink입니다. ISL 내부 전달과 목적지 downlink는 평가하지 않습니다. 기존 1011 통합 결과와 수치 비교 시 RF 방향·채널·기한이 달라졌다는 점에 유의합니다. 팀원의 ISL 코드는 변경하지 않습니다.

## 패킷 창

- 검은 박스: 기한 내 도착
- 빈 흰 박스: 최종 손실
- 주황 박스: 도착했지만 기한 초과
- 회색 박스: 아직 생성되지 않았거나 처리 중
- 최근 300개(60 pps 기준 5초)를 표시하며 각 박스에 원본 ID를 표시합니다.
- 박스를 누르면 생성·도착 시각, 대상 위성, 손실 위치·시각·원인, SNR과 PER을 확인할 수 있습니다.
- ID 입력 후 Inspect를 누르면 과거 패킷을 확인합니다. Follow를 켜면 현재 시간 추적을 재개합니다.
- 재생 중 수치는 현재까지 생성된 수를 분모로 한 잠정값입니다. 처리 중 패킷은 별도 표시하므로 최종 지표로 해석하지 않습니다.
- 손실 원인·위치는 시뮬레이터의 전체 기록입니다. 수신 위성이 누락 번호만으로 원인을 알아내는 기능이 아닙니다.

## 지표

- 손실률[%] = 최종 미도착 원본 패킷 수 / 생성 원본 패킷 수 × 100
- 기한 내 도착률[%] = 생성부터 GSL 기한 이내에 수신 완료한 수 / 생성 수 × 100
- 기한 내 전달 실패율[%] = (최종 손실 + 늦은 도착) / 생성 수 × 100
- 연속 손실: 도착 순서가 아닌 원본 ID 순서에서 손실이 이어지는 길이. 최대·평균·구간 수·단독 손실 수를 기록합니다. 기한 초과 도착은 미도착 연속 손실에 넣지 않습니다.
- 도착 시간 = 생성 + 정보 데이터 전송 시간 + 전파 지연 + 수신 처리 시간. 마지막 패킷은 생성 종료 이후라도 도착까지 관찰합니다.
- unresolved PHY는 성공이나 손실로 임의 확정하지 않고 최종 비율을 N/A로 남깁니다.

## 기본값과 가정

600초 / 160 Bytes / 60 pps / 고도 550 km / 위성 1,584개 / 고도각 마스크 25° / 히스테리시스 4°.

다음은 **실험 가정**이며 실제 Starlink 장비 값이나 검증된 맑은 날씨 통계가 아닙니다.

|---|---|
| uplink 주파수 | 14 GHz |
| 지상국 송신 전력 / 이득 | 7 dBW(약 5 W) / 28 dBi, EIRP 35 dBW |
| 위성 수신 G/T | −5 dB/K |
| 구현 손실 | 1 dB |
| 맑은 날씨 천정 감쇠 | 0.2 dB, 고도각 secant 근사 |

프레임 헤더·필러·처리 세부 지연, 간섭, 장애물, 강우, 실제 추적 오차, 잔류 Doppler에 따른 복호 열화는 아직 개별 모델링하지 않습니다. 전송 지연은 정보 비트율 기반 추상화입니다. 포화 트래픽은 큐 없이 처리하지 않고 오류로 중지합니다. 따라서 혼잡 손실은 현재 결과에 포함되지 않습니다. ML·전력 제어·중복 전송도 아직 구현하지 않습니다.

## 채널 시나리오

기본 `synthetic_fade`는 180–205초와 380–405초에 최대 10 dB의 매끄러운 인공 감쇠를 추가합니다. 신호 오류와 연속 손실 시각화를 점검하는 **제어된 시험**이며 일반적인 손실률을 재현한 결과가 아닙니다. 미래 감쇠 구간은 현재 시험 설정일 뿐, 향후 ML의 관측 입력으로 주면 안 됩니다.

```matlab
C = configGSL();
C.channelScenario = 'clear'; % 인공 감쇠 없이 동일 RF/상관 변동
C.gslDeadline_s = 0.020;     % 연구 합의 후 변경
R = main_gsl_simulation(C);
```

채널 난수와 패킷 오류 난수는 분리하며, 채널은 패킷 생성률에 의존하지 않는 시간 격자에서 생성합니다. 다음 단계에서 장비·주파수·지역에 맞는 ITU/실측 자료로 보정해야 합니다. 단순히 손실 수를 늘리기 위해 매개변수를 조정하지 않습니다.

## SNR → PER

SNR[dB] = 지상국 EIRP + 위성 G/T − FSPL − 10log10(k) − 10log10(B) − 구현·대기·시간변동 손실.

Eb/N0[dB] = SNR[dB] + 10log10(B/Rb). JPL Fig.14에서 QPSK·AR4JA r=1/2, 정보 블록 1024비트의 CWER p를 로그 보간합니다.

PER = 1 − (1 − p)^ceil(패킷 비트 수 / 1024). 160 Bytes는 정보 블록 2개입니다. 코드워드 오류 독립 가정이며 실제 복호기를 돌리지 않습니다.

곡선 위쪽은 0 대신 곡선 끝 CWER(약 1.708e−7)을 보수적 상한 근사로 유지합니다. 아래쪽은 CWER=1이라는 실패 근사를 사용합니다. 각 패킷의 phyStatus로 곡선 보간과 가정을 구별합니다. 공개 곡선이 실제 장비·복호 반복 조건과 일치하는지도 후속 검증 대상입니다.
