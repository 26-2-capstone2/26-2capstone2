# 팀 공유: 높은 PHY 손실률 — 미해결

## 현재까지 완료

- 6×11 이동 격자의 위성별 SNR·가시성 조회, 실제 위성 ID 선택과 핸드오버 연동.
- 기존 저장 DDQN 모델에 히스테리시스 0 / 0.1 / 0.3 / 0.5 dB를 적용해 각각 10회 평가.
- 같은 회차는 동일한 SNR·패킷 난수로 비교하고 손실률·최대 연속 손실·20 ms 내 도착률·핸드오버 횟수 기록.
- 40회 모두 전체 손실과 원인별 손실 합계가 일치하며, 전환 조건과 24,000개 선택 기록도 검증.

## 남겨둔 문제

현재 평균 손실률이 약 88~94%로 높다. 0.3 dB 조건의 10회 평균은 PHY 손실 30,964.5개, 핸드오버 손실 735.6개, 연결 불가 손실 0개다. 생성 패킷은 회차마다 36,000개이므로 손실 대부분은 PHY에서 발생한다.

위성 배치·거리 조건을 바꾼 뒤에도 송수신 설정과 감쇠 8 dB는 유지했고, 모델도 이전 환경에서 저장한 DDQN을 사용했다. 이 조건들이 현재 환경에 적절한지 아직 확인하지 않았다. 높은 손실률이 실제 위성망의 일반적인 성능이라는 뜻은 아니다.

현재 오류율 계산은 QPSK + AR4JA(부호율 1/2, 정보 블록 1024비트) 참고표를 사용한다. 표 아래는 UNIT_CWER(블록 오류율 1), 위는 ZERO_CWER(블록 오류율 0) 연구 가정을 적용한다. 표의 0 dB 지점도 블록 오류율 1로 기록돼 있어, 범위 밖 처리만 바꿔도 손실이 크게 줄어든다고 보장할 수 없다. SNR 0 dB 이하에서 실제 모든 통신 방식의 패킷이 전부 손실된다는 의미는 아니다.

부드러운 S자 오류율 근사는 논의와 시험 계산만 했다. **실제 시뮬레이션 코드에는 아직 적용하지 않았다.** 이번 40회 결과는 기존 참고표·ZERO_CWER·UNIT_CWER 정책의 결과다.

## 다음에 확인할 것

1. 환경감쇠와 랜덤 SNR 변동을 끈 상태에서 거리별 기본 SNR을 확인한다.
2. 송신 전력·안테나 이득·수신 성능·대역폭·정보 전송률의 근거와 상호 일관성을 점검한다. 트래픽 생성률 76.8 kbps와 현재 무선 정보율 50 Mbps를 혼동하지 않는다.
3. 기본 링크를 점검한 뒤 환경감쇠 8 dB의 적절성과 현재 격자에서의 DDQN 재학습 필요성을 검토한다.

**현재는 미해결 문제로 기록하고 기존 설정을 유지한다.** 손실률을 낮추기 위한 임의 확률 보정은 하지 않는다. 히스테리시스 비교 결과도 이 설정과 모델에 한정해서 해석한다.
