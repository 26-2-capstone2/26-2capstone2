# 기존 고도각 방식과 DDQN — 동일 조건 10회 비교

기존 방식은 학습하지 않는다. 기존 `selectServingSatellite` 함수의 고도각 최대·4° 초과 전환 규칙을 그대로 실행한다.

2026-11-23에 완료한 DDQN의 평가 시드 20269301~20269310, 저장된 위성 움직임·설정과 툴박스 PHY 표를 사용한다. 모든 후보 위성 SNR과 Packet ID별 난수, 저장된 DDQN PER를 대조한 후 기준 방식만 실행한다. DDQN을 재학습하거나 가중치를 바꾸지 않는다.

- 공통: 6×11, 6 dB, 600초, 60 pps·160 B, 기한 20 ms, 전환 중단 100 ms.
- 변경: 위성 선택과 전환 규칙. 기존 4° 마진과 DDQN Q값 0.02 마진은 다른 단위다. 비교 대상은 각 규칙을 포함한 전체 정책이다.
- 저장: `baseline_runs.csv` 10회, `ddqn_runs.csv` 기존 10회, `comparison_summary.csv` 평균·편차·차이, `paired_differences.csv` 회차별 차이.
- 각 `repeat_XX`에 기준 방식의 전체 36,000개 패킷, 연속 손실, 선택 기록과 재생 자료. DDQN 원본 파일은 기존 폴더에서 재사용한다.

상위 gsl 폴더에서 `main_gsl_compare_baseline`을 실행하면 저장 비교 그래프를 연다. `main_gsl_compare_baseline('run')`은 기준 방식 10회만 다시 평가한다. 첫 실행에 기존 DDQN 평가 결과 파일이 필요하다.

이 실험으로 고도각 기준 방식과 DDQN 정책의 차이를 비교할 수 있다. 최대 SNR 방식이 없으므로 개선 전부가 강화학습 고유 효과라고 주장할 수는 없다. 10개 테스트 시드의 통계이며 학습 초기화를 여러 번 반복한 결과는 아니다.
