# 학습률·버퍼·타깃 갱신의 단일 요인 안정성 실험

`experiment_plan.json`에 결과 확인 전 정한 조건을 저장했다.
기존 200회 모델에서 퇴보가 관찰됐으므로 새 조건은 우선 각각 200회 학습하고 100/200회에서 평가한다.
기본 조건의 결과는 앞선 `checkpoint_audit_1127`에서 재사용한다.

| 조건 | 바꾼 것 |
|---|---|
| 기본 | 학습률 3e-4, 버퍼 20,000, 100번마다 타깃 복사 |
| low_lr | 학습률만 1e-4 |
| large_buffer | 버퍼만 60,000 |
| soft_target | 타깃 갱신만 매 업데이트 1% 반영 |

보상, 환경, 11개 입력, 64-64 네트워크, 초기값, 학습 환경 시드 순서, 탐험률 일정,
배치·warmup·학습 주기·클리핑·Q마진을 유지한다.
중간 평가에서 학습용 난수를 소비하거나 Adam·버퍼를 초기화하지 않는다.

## 실행

- 상위 `gsl`에서 `main_gsl_stability_comparison`: 저장 결과 열기, 재학습 없음.
- `train_low_lr.m`, `train_large_buffer.m`, `train_soft_target.m`: 각 조건 새 200회 학습·20회 평가.
- `verify_entry.m`: 원본과 계측 기본 설정의 일치, 순수 추론의 RNG 보존, 부드러운 타깃 수식 검증.
- `probe_saved_stability`: 문제가 된 고정 상태에서 모든 체크포인트의 후보별 Q·타깃 Q·PER 확인.

## 기록

각 `results_*` 폴더에 200회 학습 기록, 100/200회 체크포인트, 회차별 전체 패킷·선택·연속 손실·preview MAT를 저장한다.
`learning_diagnostics.csv`는 100번 학습 업데이트마다 gradient norm, clip scale,
온라인-타깃 차이, 표본 경험 나이, 전체 후보 성공률 20% 미만 상태의 표본·버퍼 비율,
기준 상태의 64번 대비 44번 Q점수 차이를 기록한다.
두 후보의 Q차이만으로 최선의 후보를 판정하면 안 되므로 `fixed_probe_candidates.csv`에 모든 후보도 별도 저장한다.

## 한계

학습 초기값은 조건마다 하나다. 성능을 확정하는 실험이 아닌 원인을 좁히기 위한 파일럿이다.
버퍼 확대는 샘플·공유 난수 경로를, 타깃 반영은 갱신 방식·평균 지연을 함께 바꿀 수 있다는 한계를 명시한다.
실험에 사용한 시드는 검증용이며 최종 모델 성능은 새 시드·여러 초기값에서 별도 검증해야 한다.
마지막 모델을 자동 채택하지 않고, 기본 200회뿐 아니라 기존 100회 모델과의 비교도 함께 본다.

## 종료 경험 진단

`diagnose_terminal_samples`는 학습 없이 에이전트의 샘플링 난수만 재구성한다.
기록된 환경 step·update 및 표본 경험의 평균 나이가 모두 일치하는지 검증하고,
그 배치에 600초 종료 전이가 있었는지 표시한다. `terminal_sample_summary.csv`를 확인한다.
11개 입력에 남은 시간이 직접 없으나 종료 전이에서는 미래 가치를 0으로 둔다는 설계상 위험을 별도 단서로 기록했다.
종료 경험과 큰 loss의 동반 발생은 원인 확정이 아니며, 실제 종료와 단순 관측 창을 구분한 추가 검증이 필요하다.
