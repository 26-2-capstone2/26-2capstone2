# 강화학습 과정 (route_C, 온라인 Double DQN)

C가 배우는 과정을 `rl/train_rl.py` 기준으로 정리함.

## 1. 큰 흐름: 에피소드 반복

```
에피소드 1 (base, 시드 1001) → 에피소드 2 (high, 1002) → 에피소드 3 (severe, 1003) → … → 에피소드 60
```

- 에피소드 하나 = 30초짜리 시뮬레이션 한 번
- 에피소드마다 혼잡 단계(base → high → severe)와 핫스팟 배치(시드)가 바뀜
- 신경망은 처음부터 끝까지 하나이며, 계속 고쳐 나감

## 2. 에피소드 안에서 (1 ms마다)

시뮬레이터가 1 ms씩 진행하며, 패킷이 위성에 도착할 때마다 아래 과정을 거침.

### (1) 보기 (State)
- 그 위성이 주변 정보 24개를 봄
- 4방향 큐 길이, 이웃 부하, 큐 증가 속도, 최근 넘침, 링크 유무, 남은 거리, 남은 기한, 남은 TTL

### (2) 고르기 (Action)
- 링크가 없는 방향만 제외함 (행동 마스크, `maskMode='link'`)
- 꽉 찬 큐, 기한 안에 못 가는 방향은 막지 않고, 손실 보상으로 직접 피하는 법을 배움
- 예전 방식(셋 다 막음)은 `maskMode='full'`로 비교 실험 가능
- 확률 ε만큼은 무작위로 고름 (탐험)
- 나머지는 신경망의 Q값이 가장 큰 방향으로 보냄

### (3) 결과 받기 (Reward)
| 언제 | 보상 |
|---|---|
| 매 홉 | −(링크 지연 + 큐 길이 ÷ 5) ÷ 70 |
| 기한 내 도착 (끝) | +1 |
| 단발 손실 (1~2개) | −0.5 |
| 연속 손실 (3개 이상) | k번째 패킷 −min(2.0, 1.0 + 0.1 × max(0, k − 3)) → −1.0 ~ −2.0 |

- 연속 손실 여부는 앞뒤 패킷 결과를 기다렸다가 정함
- 연속 손실이면 처음 2개를 포함한 구간 전체가 연속 손실 보상을 받음

### (4) 경험 저장
- (본 것, 고른 방향, 받은 보상, 다음 위성에서 본 것)을 경험 카드 한 장으로 만듦
- 리플레이 버퍼에 넣음 (최대 20만 장)
- 위성 36개의 경험이 모두 한 버퍼에 모임 (중앙 학습, CTDE)

### (5) 배우기
- 결정 4번마다 한 번, 버퍼에서 카드 64장을 무작위로 꺼냄 (경험 5,000장이 쌓인 뒤부터)
- 목표값 = 받은 보상 + 0.95 × (다음 상태에서 앞으로 받을 점수)
- 신경망 예측이 목표값에 가까워지도록 고침
- Double DQN: 다음 상태의 최고 방향은 학습 신경망이 고르고, 그 점수는 타깃 신경망이 매김
- 학습 2,000번마다 타깃 신경망을 새로 복사함

## 3. 학습 진행에 따른 변화

| 시점 | ε (무작위 비율) | 모습 |
|---|---|---|
| 처음 (1 에피소드) | 1.0 → 0.9 | 거의 무작위로 가 보며 경험을 모음. 손실 많음 |
| 중간 (약 5~10 에피소드) | 0.6 → 0.1 | 배운 것을 점점 많이 씀. 손실이 빠르게 줄어듦 |
| 이후 (약 11 에피소드부터) | 0.05 | 거의 배운 대로 행동하며 다듬음 |

- ε은 결정 30만 번에 걸쳐 1.0에서 0.05로 줄어듦 (6x6 기준 약 10~11 에피소드)

## 4. 저장

저장 위치: `~/rl_models/routeC[_구조]_날짜/`

| 파일 | 내용 |
|---|---|
| `model_ep10.pt`, `model_ep20.pt`, … | 10 에피소드마다 저장한 모델 |
| `model_final.pt` | 학습이 끝났을 때의 최종 모델 |
| `train_log.csv` | 에피소드별 도착률, 연속 손실, ε, 보상 성분, 학습 오차 등 (학습 곡선용) |
| `run_info.txt` | 학습 조건 (grid 구조, 에피소드 수, 강화학습 설정값) |

## 5. 학습이 끝난 뒤 (평가)

- 저장된 모델을 불러와 ε = 0 (무작위 없음), 신경망 고정으로 실행함
- 학습 때 쓰지 않은 평가 시드 1~20에서 A(Dijkstra), B(DRA)와 같은 조건으로 비교함
- 실행: `python eval_routes.py 모델경로` 또는 `python run.py`에서 "A, B, C 비교 평가" 선택

## 6. 한 줄 요약

위성 36개가 길을 골라 보고, 그 결과를 한곳에 모아 신경망 하나를 고치는 과정을 30초 시뮬레이션마다 반복함.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `config_rl.py` | 강화학습 설정값 (관측 정규화, 보상 값, 신경망 크기, 학습률, 버퍼, ε 일정, 시드) |
| `rl_state.py` | State 24개와 행동 마스크 계산 |
| `rl_reward.py` | 홉, 도착, 단발 손실, 연속 손실 보상 계산 |
| `rl_agent.py` | DQN 신경망, 타깃 신경망, 리플레이 버퍼, Double DQN 학습, ε-greedy |
| `rl_collector.py` | 결정들을 경험 (s, a, r, s′)으로 이어 버퍼에 넣음. 단발/연속 손실 판정 후 보상 부여 |
| `train_rl.py` | 학습 실행 (에피소드 반복, 모델과 기록 저장) |
