# 강화학습 과정 (route_C, 온라인 Double DQN)

C가 배우는 과정을 `rl/train_rl.py` 기준으로 정리함.

## 1. 큰 흐름: 에피소드 반복 + 검증 평가

```
검증 0 (학습 전) → 에피소드 1 (base, 시드 1001) → 에피소드 2 (high, 1002) → 에피소드 3 (severe, 1003) → …
→ 에피소드 10 → 검증 1 → … → 에피소드 270 → 검증 27
```

- 에피소드 하나 = 10초짜리 시뮬레이션 한 번 (결정 약 7천~8천 번)
- 에피소드마다 혼잡 단계(base → high → severe)와 배경 트래픽(시드)이 바뀜
- 신경망은 처음부터 끝까지 하나이며, 계속 고쳐 나감
- 학습 시작 전과 10 에피소드마다 학습을 멈추고, 검증 시드 501~505로 ε 0 평가 → `eval_log.csv` (학습 곡선)
- 학습 시드(신경망 초기값)를 바꿔 여러 번 학습: `python rl/train_rl.py 270 0 0`, `… 0 1`, `… 0 2`

## 2. 에피소드 안에서 (1 ms마다)

패킷이 위성에 도착할 때마다 아래 과정을 거침.

### (1) 보기 (State 24개)
- 4방향 큐 길이, 이웃 부하(링크 지연만큼 늦게 받은 값), **큐 증가 속도, 최근 큐 넘침**, 링크 유무, 남은 거리 2, 남은 기한, 남은 TTL
- 큐 증가 속도와 최근 큐 넘침은 큐가 넘치기 전의 징후 (연속 손실은 주로 큐가 꽉 차 패킷이 연달아 버려질 때 생김)

### (2) 고르기 (Action)
- 상, 하, 좌, 우 중 하나. 링크가 없는 방향만 제외함 (행동 마스크, `maskMode='link'`)
- 꽉 찬 큐, 기한 안에 못 가는 방향은 막지 않고 손실 보상으로 직접 피하는 법을 배움 (예전 방식은 `maskMode='full'`)
- 확률 ε만큼 무작위로 고름 (탐험), 나머지는 Q값이 가장 큰 방향

### (3) 결과 받기 (Reward)
| 언제 | 보상 |
|---|---|
| 매 홉 | −(링크 지연 + 큐 길이 ÷ 링크 용량) ÷ 70 |
| 기한 내 도착 (끝) | +0.5 |
| 단발 손실 (1~2개) | −0.1 |
| 연속 손실 (3개 이상) | k번째 패킷 −min(1.0, 0.2 + 0.1 x max(0, k − 3)) → −0.2 ~ −1.0 |

- 연속 손실 여부는 앞뒤 패킷 결과를 기다렸다가 정함 (`rl_collector.py`)
- 연속 손실이면 처음 2개를 포함한 구간 전체가 연속 손실 보상을 받음
- 상한(−1.0)을 두어 드문 대형 손실이 학습 전체를 흔들지 않게 함

### (4) 경험 저장
- (본 것, 고른 방향, 받은 보상, 다음 위성에서 본 것)을 경험 하나로 만들어 리플레이 버퍼에 넣음 (최대 100만 개)
- 위성들의 경험이 모두 한 버퍼에 모임 (중앙 학습, CTDE)

### (5) 배우기
- 경험 5만 개가 쌓인 뒤부터, 결정 4번마다 한 번 버퍼에서 64개를 무작위로 꺼내 학습
- 목표값 = 받은 보상 + 0.95 x (다음 상태에서 앞으로 받을 점수)
- Double DQN: 다음 상태의 최고 방향은 학습 신경망이 고르고, 그 점수는 타깃 신경망이 매김
- 학습률 0.0001 (Adam), Huber 손실, 기울기 최대 10
- 학습 2,500번(= 결정 1만 번)마다 타깃 신경망을 새로 복사

## 3. 학습 진행에 따른 변화

| 시점 | ε (무작위 비율) | 모습 |
|---|---|---|
| 처음 (약 1~7 에피소드) | 1.0 → 약 0.85 | 경험만 모음 (5만 개 쌓일 때까지 학습 안 함) |
| 탐험 구간 (약 40 에피소드까지) | → 0.05 | 무작위를 줄이며 배운 것을 점점 많이 씀 |
| 이후 (약 40~270 에피소드) | 0.05 | 거의 배운 대로 행동하며 다듬음 |

- ε은 결정 30만 번에 걸쳐 1.0에서 0.05로 줄어듦 (전체 학습 약 200만 번의 15%)
- 학습 중 성능에는 ε 무작위가 섞여 있어서, 실제 실력은 검증 평가(ε 0)로 봄

## 4. 학습 목표와 판정

학습이 끝나면 `python analysis/learning_targets.py 학습폴더 [학습폴더 ...]`로 판정.

| 목표 | 기준 |
|---|---|
| 학습 진행 | 최종 도착률이 시작보다 5%p 이상 상승 |
| T50, T90 | 오른 폭의 50%가 전체 학습의 20% 이후, 90%가 40~70% 사이 |
| 평가 점, 급상승 | 25개 이상, 연속한 두 점 사이 15%p 이하 |
| 수렴 | 최근 평가 3번 도착률 차이 2%p 이내, 연속 손실 ±20% 이내, 학습 손실이 커지지 않음, 전체의 75% 이전 |
| 안정성 | 수렴 뒤 하락 5%p 이하, 발산 없음, 학습 시드 간 표준편차 3%p 이하 |

## 5. 저장

저장 위치: `~/rl_models/routeC[_구조]_날짜_s학습시드/`

| 파일 | 내용 |

| `model_ep10.pt`, `model_ep20.pt`, … | 10 에피소드마다 저장한 모델 |

| `eval_log.csv` | 검증 평가 (단계별 도착률, 1분당 연속 손실, 95번째 백분위 길이, 누적 결정 수) |
| `learning_targets.md`, `learning_curve_eval.png` | 학습 곡선 목표 판정 결과 (판정 스크립트를 돌리면 생김) |
| `run_info.txt` | 학습 조건 |

## 6. 학습이 끝난 뒤 (최종 평가)

- 학습 시드별 모델을 한 번에 평가: `python eval_routes.py 모델0,모델1,모델2`
- ε 0, 신경망 고정, 학습 때 쓰지 않은 평가 시드 1~20에서 A(Dijkstra), B(DRA)와 같은 조건으로 비교
- 판정: `python analysis/compare_runs.py 평가폴더` → B 대비 연속 손실 감소, 도착률, 지연, 짝지은 승률, 95% 신뢰구간

## 관련 파일

| 파일 | 역할 |
|---|---|
| `config_rl.py` | 강화학습 설정값 (관측 정규화, 보상, 신경망, 학습률, 버퍼, ε, 검증 평가, 시드) |
| `rl_state.py` | State 24개와 행동 마스크 |
| `rl_reward.py` | 홉, 도착, 단발 손실, 연속 손실 보상 |
| `rl_agent.py` | DQN 신경망, 타깃 신경망, 리플레이 버퍼, Double DQN 학습, ε-greedy |
| `rl_collector.py` | 결정들을 경험 (s, a, r, s′)으로 이어 버퍼에 넣음. 단발/연속 손실 판정 후 보상 부여 |

| `학습안정화_기록.md` | 학습 안정화 테스트 기록 |
